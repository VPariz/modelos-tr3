# Trabalho 3 - Modelos Probabilísticos

Scripts em Python para o Trabalho 3 da disciplina de Modelos Probabilísticos (IME).

## Estrutura

- `Plot.py`: script que lê os dados, calcula média, variância, desvio padrão, VMQ e RMS, e gera os gráficos e histogramas.
- `dados/`: pasta onde devem ficar os arquivos `.txt` de entrada.
- `resultados/`: pasta criada automaticamente pelo script para salvar os gráficos gerados e o arquivo `estatisticas.txt`.

## Como rodar

Instalar as bibliotecas necessárias:
```bash
pip install -r requirements.txt
```

Colocar os arquivos `.txt` dentro da pasta `dados/` e rodar:
```bash
python Plot.py
```
